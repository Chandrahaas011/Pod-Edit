# Archived GUI Implementation Plan

Updated: 2026-08-11

The former v9 GUI plan depended on MediaPipe, deleted GUI entry points, and
superseded pipeline modules. It is not an active implementation plan.

PodEdit 1.4 is intentionally CLI-first while editorial accuracy is still being
evaluated. The maintained entry point is `main.py`, the engine is `pipeline/`,
and the current acceptance work is documented in `README.md`, `HANDOFF.md`, and
`RESEARCH_PLAN.md`. GUI or executable packaging should resume only after the
multi-episode human-reference study establishes a stable core engine.
